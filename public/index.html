features.js

1// Built for the stage

2HYDRACTRL wraps hydra, Olivia Jack's live-codable video synth, in tools for performing. Recall a scene instead of typing it, play it with a controller, and keep the code one keystroke away.

  • 01Scenes

    // 64 scenes in 4 banks of 16 slots, with thumbnails so you find them mid-set.

  • 02MIDI

    // Made for the Korg nanoPAD2. Pads recall scenes and switch banks; the touchpad feeds nanoX and nanoY into your sketches.

  • 03XY pad

    // Flick it and a small physics engine keeps it bouncing. Works with a mouse too.

  • 04Editor

    // CodeMirror 6 with hydra-aware completions, error messages and auto-run, set in Fira Code with ligatures.

  • 05Audio

    // hydra's a.fft out of the box, with a watchdog that revives audio when the browser suspends it.

  • 06Breakout window

    // Send the visuals to a second window at an exact size, for a projector, a recording or an OBS window capture.

  • 07Themes

    // Five interface themes. Dial the panels down to see your visuals.

  • 08Setup code

    // A setup tab that runs before every sketch, for audio settings and globals.

  • 09hydra docs

    // Every hydra function with parameters and examples, one click away.

  • 10Banks

    // Save all 64 slots, thumbnails included, as one JSON file.

  • Your own images and videos

    In the desktop app, drop a picture or a clip on the editor. HYDRACTRL copies it into its media folder and writes the line that loads it, like s0.initVideo("/media/clip.mp4").

  • Sketches as links

    Alt/⌥ + U copies a link with your sketch inside. Whoever opens it sees it running. The background of this page works the same way.

  • Plugins

    Every feature is a plugin on a small core, so a broken one can't take down a live set. Write your own with the plugin docs.

How it works

The desktop app renders your set in a hidden second window and shares every frame as a GPU texture, through a Syphon server on macOS or a Spout sender on Windows. No screen capture, no extra latency, and it follows every run, slot change and XY pad move.

Works with

targets = [
  • "Resolume"
  • "MadMapper"
  • "VDMX"
  • "TouchDesigner"
  • "OBS"
  • "Millumin"
] // and anything that speaks Syphon or Spout

Tested at 1080p and 4K, a steady 60 fps into Resolume on an Apple Silicon Mac. Spout on Windows is new, so tell us how it runs.

Both versions keep your scenes on your computer. Move them between the two with bank export and import (Alt/⌥ + X / I).

Which Mac do I have? Apple menu → About This Mac. "Chip: Apple M…" means Apple Silicon, "Processor: Intel" means Intel.

Linux? Syphon and Spout don't exist there, so use the browser version, or run the desktop app from source.

{…}Opening the app for the first time

macOS

  1. Open the DMG and drag HYDRACTRL into Applications.
  2. Open it. The builds aren't notarized by Apple yet, so macOS blocks the first launch.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.
  4. Allow microphone access when asked, for audio-reactive sketches.

Windows

  1. Run the installer. The builds aren't code-signed yet, so SmartScreen may warn about an unrecognized app.
  2. Click More info, then Run anyway.
  3. HYDRACTRL shows up in the Start menu. The Spout sender is called HYDRACTRL.

Release notes are in the changelog, every version is on the releases page, and the desktop README explains how to build it yourself.
