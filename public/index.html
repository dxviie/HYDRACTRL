HYDRACTRL

A performance wrapper around hydra for live visuals: scenes, MIDI and an XY pad for the moments you don't want to be coding, and a proper editor for when you do.

Desktop

Straight into your VJ software

HYDRACTRL Desktop renders your set in a second, hidden window and shares every frame as a GPU texture: a Syphon server on macOS, a Spout sender on Windows. No screen capture, no extra latency, and it follows the interface live: every run, slot change and XY-pad move.

HYDRACTRL Desktop → Syphon · Spout →
  • Resolume
  • MadMapper
  • VDMX
  • TouchDesigner
  • OBS
  • Millumin
  • anything that speaks Syphon or Spout

Tested at 1080p and 4K, a steady 60 fps into Resolume on an Apple Silicon Mac. Spout on Windows is new: tell us how it runs.

Opening the app for the first time

macOS

  1. Open the DMG and drag HYDRACTRL into Applications.
  2. Open it. The builds aren't notarized by Apple yet, so macOS blocks the first launch.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.
  4. Allow microphone access when asked, for audio-reactive sketches.

Windows

  1. Run the installer. The builds aren't code-signed yet, so SmartScreen may warn about an unrecognized app.
  2. Click More info, then Run anyway.
  3. HYDRACTRL shows up in the Start menu; the Spout sender is called HYDRACTRL.

Release notes live in the changelog; every version and its checksums are on the releases page. Prefer to build it yourself? See the desktop README.

Features

Built for the stage

HYDRACTRL wraps hydra, Olivia Jack's live-codable video synth, in a set of tools for performing: recall a scene instead of typing it, play it with a controller, keep the code one keystroke away.

Scene management

Store and recall up to 64 scenes in 4 banks of 16 slots, with thumbnails so you can find them mid-set.

MIDI control

Built around the Korg nanoPAD2: pads recall scenes and switch banks, the XY pad feeds nanoX and nanoY into your sketches.

XY pad with physics

Flick the XY pad and let a small physics engine keep it bouncing. Works with a mouse too.

A real code editor

CodeMirror 6 with hydra-aware highlighting, completions, error messages and auto-run.

Audio reactivity

hydra's a.fft out of the box, watched over by a watchdog that revives audio when the browser suspends it.

Breakout view

Send the visuals to a second window at an exact size, for a projector, a recording or an OBS window capture.

Themes

Five interface themes with matching editor colors, and panel opacity you can dial down to see your visuals.

Setup code

A setup tab that runs before every sketch, for audio settings and globals you always want around.

hydra docs built in

Every hydra function with its parameters and examples, one click away while you code.

Import and export banks

Save all 64 slots, thumbnails included, as one JSON file to back up or share.

Share sketches as links

Alt/⌥ + U copies a link with your sketch inside it. Whoever opens it sees it running straight away, without touching their own scenes. The background of this page works the same way: open it from the corner.

Plugins

New features are isolated plugins on a small core, so a broken one can't take down a live set. Write your own with the plugin docs.

Shortcuts

Keep your hands on the keys

Ctrl/⌘ + Enter
Run the current code
Ctrl/⌘ + S
Save code to the active slot
Ctrl/⌘ + `
Hide or show the interface
Esc
Bring back a hidden interface
Ctrl/⌘ + Y
Toggle auto-run
Alt/⌥ + U
Copy the sketch as a link
Alt/⌥ + 0–9 / A–F
